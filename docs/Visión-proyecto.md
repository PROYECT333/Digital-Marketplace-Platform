# Digital Marketplace Platform - Visión del Proyecto

## 1. Descripción General del Proyecto

-Digital Marketplace Platform es una aplicación web full-stack diseñada para conectar compradores y vendedores en un entorno digital fácil de usar. 
La plataforma permitirá a los usuarios explorar productos, gestionar cuentas y realizar compras de forma segura en línea.

Este proyecto se desarrolla como parte de un portafolio profesional para demostrar habilidades en desarrollo de software, 
integración backend, diseño de bases de datos y prácticas de aseguramiento de calidad.

## 2. Planteamiento del Problema

-Muchas pequeñas empresas no cuentan con plataformas digitales accesibles para vender sus productos de manera eficiente. 
Las soluciones existentes suelen ser costosas, complejas o no están adaptadas a sus necesidades.

Esta plataforma busca ofrecer una solución de marketplace escalable, accesible y fácil de usar tanto para negocios como para clientes.

## 3. Objetivos

- Construir una interfaz de marketplace responsiva e intuitiva.  
- Desarrollar un backend seguro utilizando Java con Spring Boot.  
- Implementar PostgreSQL para la persistencia de datos.  
- Aplicar buenas prácticas de ingeniería de software.  
- Documentar todo el ciclo de desarrollo como parte del portafolio profesional.  

## 4. Usuarios Objetivos

- Propietarios de pequeños negocios  
- Compradores en línea  
- Administradores del sistema del marketplace  

## 5. Funcionalidades Principales

- Registro e inicio de sesión de usuarios  
- Catálogo de productos  
- Sistema de carrito de compras  
- Procesamiento de pedidos  
- Panel de administración  
- Gestión de inventario  

## 6. Tecnologías y Herramientas

- Frontend: HTML, CSS, JavaScript  
- Backend: Java + Spring Boot  
- Base de Datos: PostgreSQL  
- Control de versiones: Git y GitHub  
- Gestión del proyecto: Jira (metodología Scrum con sprints y tablero Kanban)  
- Pruebas: Manuales y prácticas QA (automatización con Selenium)  

## 7. Criterios de Éxito

-El proyecto será considerado exitoso si se logra un prototipo funcional completo con arquitectura documentada, pruebas realizadas 
y estructura lista para despliegue.
