# Digital Marketplace Platform

## Description
A full-stack marketplace platform designed to connect buyers and sellers in a secure, scalable, and user-friendly digital environment.

## Objective
To develop a robust web-based solution that supports product listings, user management, transactions, and administrative operations.

## Tech Stack
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- PostgreSQL

## Quality Assurance
This project includes QA practices such as functional testing, bug reporting, and validation processes.

Phase 1 - Project Foundation
